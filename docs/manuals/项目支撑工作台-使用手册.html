1. 这是什么系统

「项目支撑工作台」帮助小团队管理多个项目、任务、周报/日报。 电脑浏览器打开 PC 端；手机在钉钉里打开 H5 页面。两边数据是通的：电脑交办的任务，手机待办里也能看到。

一句话记住： 打开就能看到「今天该看什么」和自己的待办；写任务会自动进周报草稿；写周报/做任务后可以看对自己的评价。

2. 怎么登录

2.1 地址一览

入口地址说明
统一登录入口 https://app.fywasu.com:18090/ 浏览器打开后进入工作台登录
PC 工作台 https://app.fywasu.com:18090/workbench/ 电脑浏览器：钉钉扫码或账号密码
钉钉手机端 https://app.fywasu.com:18090/workbench/m/ 钉钉内打开，一般可免登

2.2 PC：钉钉扫码（推荐）

  1. 用电脑浏览器打开 PC 地址，默认看到「钉钉扫码」。
  2. 打开手机钉钉，扫描页面上的二维码并确认。
  3. 账号已绑定且有「钉钉免登」权限 → 直接进入个人工作台。
  4. 若提示未绑定：用系统账号 + 密码绑一次即可（同样需要免登权限）。

2.3 PC：账号密码

  1. 在登录页切换到「账号密码」。
  2. 输入管理员发放的用户名与密码。
  3. 首次登录必须改密：新密码至少 8 位，需同时包含大写字母、小写字母和数字。
自愿改密：登录后点右上角姓名 →「修改密码」。

2.4 钉钉端登录

  1. 在钉钉工作台打开「项目支撑工作台」应用（由管理员配置移动端首页）。
  2. 已授权免登时，打开即可进入，无需再输密码。
  3. 若无法免登，按页面提示用系统账号绑定，或联系管理员开通「钉钉免登」并绑定钉钉账号。

3. 角色与权限

不同角色看到的菜单和数字不一样，用生活例子理解：

角色大概能做什么
普通成员 看全部项目列表；管自己的任务/周报/待办；看对自己的评价。不能看别人周报。
项目负责人 在普通成员基础上，可交办任务；可改自己负责的项目信息。
部门负责人 看团队概览（全部任务、周报提交、重点项目/任务、质量告警、部门待办）；可看全员周报工作台。
系统管理员 部门负责人能力 + 用户/角色/模型等系统管理。
看全部 ≠ 改全部：大家都能看项目列表；改项目名称/类型，一般只有该项目负责人或管理员可以。

4. PC 端使用说明

登录后默认进入个人工作台。左侧是菜单，右上角点姓名可改密或退出。

4.1 个人工作台（首页）

  • 今天该看什么：AI 根据当前情况写一段白话提醒（文字会慢慢出来，不用干等转圈）。
  • 我的概览 / 团队概览：
    • 普通成员：我的任务、本周周报、我的项目、个人待办。
    • 部门负责人 / 超管：全部任务、团队周报、全部项目、部门待办，以及重点项目、重点任务、质量告警。
  • 常用操作：写任务、写周报/日报、看评价、项目管理、周报工作台（有权限才显示）等快捷按钮。
  • 与我相关：待办任务、卡点跟进、我的项目列表。
  • 团队 · 部门待办（仅管理者）：其他人未完成的待办，方便催办。

4.2 项目管理

  • 查看全部项目的分级、阶段、卡点、任务完成率、周报情况。
  • 可按「重点 / 普通 / 日常」、类型、名称筛选。
  • 有权限时可新建项目；负责人/管理员可编辑项目名称与类型。
  • 项目类型目前为三类：软件开发 / 系统集成 / 集众融合。
  • 点进项目可看阶段、卡点、任务与成员角色。
请按真实立项名称建项目；杂项工作请归入系统内的「日常任务」，不要随便起假名。

4.3 写任务

  1. 侧栏点「写任务」（需自建任务权限）。
  2. 填写：关联项目、标题、目标（做成什么样）、时间、任务级别（P0～P4）。
  3. 可选：自己做，或交办给同事（管理者/项目负责人）。
  4. 保存后：进入对方/自己的待办，并自动写入本周周报草稿（本周已提交的周报不会被改）。

4.4 写周报 / 日报

  • 日报：当天记录，看板显示已记/未记，不催办、不考核。
  • 周报：正式汇总；可写做成了什么、有无卡点、下一步计划。
  • 支持 AI 帮忙整理结构（点「采用」才写入）；提交后「下一步」可进入本人待办。
  • 填写标准详见系统内说明；结果尽量写具体，少用「推进中」「已完成」这种空话。

4.5 看评价

侧栏「看评价」：查看自己周报的一阶段评价、自己负责任务/辅助任务的评价。没有内容时，先提交周报或完善任务再回来看。

4.6 周报工作台（管理者）

需「查看所有周报」权限。可看全员提交情况、质量告警、催办未交周报（系统管理员账号一般不计入应提交名单）。

4.7 方案库

有权限时可查阅、上传历史方案，便于复用经验。

4.8 系统管理（管理员）

  • 用户管理、角色权限、审计、模型管理等。
  • 给角色勾选「钉钉免登」后，员工才能用钉钉扫码/免登。

5. 钉钉端使用说明

底部四个 Tab：首页 · 待办 · 周报 · 我的。

5.1 首页

  • 快捷入口：写任务、看周报、写周报、项目管理等（随权限变化）。
  • 可看待办摘要、部门待办（管理者）、卡点与项目入口。
  • 有权限者可进入周报看板看全员情况。

5.2 待办

  • 我的未完成任务；可点进详情改状态、填结果。
  • 管理者可看「部门待办」汇总。

5.3 周报

  • 底部「周报」进入我的周报：历史周期、正文与评价；可再点「写周报」。
  • 首页「看周报」同样进我的周报；「写周报」直达填写页。

5.4 我的

  • 查看姓名、角色、钉钉绑定状态。
  • 「看评价」入口在此；也可改密相关能力（以页面实际为准）。
钉钉端与 PC 端共用同一套后台数据。电脑上交办给你的任务，手机「待办」里马上能跟进。

6. 日常工作怎么做（按场景）

场景 A：今天开始干活

  1. 打开 PC 个人工作台或钉钉首页。
  2. 先看「今天该看什么」和待办列表。
  3. 有交办未接收的，先接收再干。

场景 B：给自己或同事建任务

  1. 写任务：定项目、目标、时间、级别。
  2. 保存 → 进待办 + 进本周周报草稿。
  3. 交办时，对方待办与部门待办（管理者）都会出现。

场景 C：周五写周报

  1. 打开「写周报/日报」，核对自动带入的任务卡。
  2. 补全结果、卡点、下一步；可用 AI 整理后点采用。
  3. 提交。之后可在「看评价 / 我的周报」里看反馈。

场景 D：管理者盯风险

  1. 个人工作台看团队概览：周报是否齐、重点任务、质量告警、部门待办。
  2. 点质量告警 / 重点任务看明细；必要时进周报工作台催办。
  3. 项目管理页看重点项目与卡点。

7. 常见问题

现象可能原因与处理
扫码后进不去 角色未勾选「钉钉免登」，或未绑定钉钉账号 → 找管理员开通并绑定。
强制改密过不去 新密码须 ≥8 位，且含大写、小写、数字。
看不到周报工作台 需要「查看所有周报」权限（部门负责人通常有，普通成员没有）。
团队概览仍是「我的」四张卡 当前账号不是部门负责人/系统管理员，或权限未生效 → 重新登录或联系管理员。
任务没进周报 本周周报若已提交，新任务不会改已交内容；可下周再体现，或在草稿阶段保存任务。
钉钉页还是旧的 强制刷新或清缓存后再打开 …/workbench/m/。
打不开地址 确认使用 https://app.fywasu.com:18090/，检查网络/VPN 与证书提示是否需信任。
还需要帮助？ 把「哪一端（PC/钉钉）+ 用的哪个账号角色 + 截图」发给系统管理员，排查会更快。
