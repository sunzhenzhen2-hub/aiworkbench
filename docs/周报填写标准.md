# 周报 / 日报填写标准（轻量版）

## 双目标

1. **管理者**：了解进度、及时控风险、沉淀可量化考核素材。  
2. **员工（同等重要）**：当作**工作思路理清工具**——想清楚「做成了什么 / 卡在哪 / 下一步何时完成」。

**硬约束：不能太重。** 默认 3～5 分钟交完；无卡点不展开长表。

## 时间

- **周报**：自选开始日～结束日（默认本周一～本周日，可改）。正式汇总与考核以周报为准，看板「未交（催办）」只针对周报。  
- **日报**：选单个日期。日报是当天工作记录（类似任务流水），**不考核、不催办**；周末请把本周进展汇总到周报。

## 默认三问（每张任务卡片）

每张卡片先写 **任务概述**（短标题，本周可有多条任务），再填三问：

| 三问 | 怎么填 | 说明 |
|------|--------|------|
| 1. 做成了什么？ | 一句结果 + 可选一个数 | 禁止「跟进中 / 无进度 / 持续中」 |
| 2. 卡住或要协调吗？ | 无 / 有卡点 / 需协调 | 选「无」即跳过 |
| 3. 下一步何时完成？ | 一句目标 + 一个日期 | 日报则写「明日」；**周报提交后会把下周计划同步到「我的待办」**（AI 规范：做什么 / 做成什么样·做多少 / 截止日） |

**所属项目必选（硬拦）。** 每张卡片必须选立项项目；杂项、行政类请选「日常任务」。填写停顿后，AI 可整理字段并建议挂到项目 / 加入任务链（需点「采用」才写入）。

## 任务链（跨周进度）

- 同一件事跨周延续时，可加入**任务链**（`chain_id`），在写周报页可「查看进度」看时间线。
- 可选挂到已有**交办任务**；不会自动新建交办。
- PC 与钉钉 H5 均支持：停顿触发 AI 建议 → 采用 → 保存/提交后沉淀到链上。
- 标题或下一步以「继续推进 / 继续跟进 / 持续…」等开头时，系统会**优先匹配历史同类事项**并建议入链（忽略前缀再比对主题），避免看起来无头无尾；点「采用」才写入。
- **勿只写「继续推进」**：须写清对象 + 动作；空泛标题保存前会提示「请想清楚」。写交办时若与本人未完成任务高度相似，会引导打开已有任务，避免重复建单。

## 按需展开

### 有卡点 / 需协调

- 卡在哪（一句话）
- 下一步谁做什么
- 下次跟进日
- 需要谁帮忙（选填）
- 若已挂到项目，可关联已有卡点或新建（写入系统卡点表）

### 风险（三档）

| 档 | 何时 | 要填什么 |
|----|------|----------|
| 正常 | 默认 | 无 |
| 需关注 | 有变数但本人能扛 | 原因；影响日期选填 |
| 需升级 | 要别人协调或可能交不了 | 原因 + 影响日期 + 协调对象（必填） |

## 硬拦截（与代码一致）

1. **未选所属项目**（杂项请选「日常任务」）  
2. 任务概述为空（有实质动作时）  
3. 「做成了什么」是空话  
4. 选了有卡点/需协调却缺跟进日或下一步；或选了「需升级」却缺协调对象/影响日期  

其余（缺数字、疑似漏报）仅黄灯软提示，不挡提交。

## 主负责人与辅助人

- 每个项目**唯一**主负责人；可有多名辅助人。  
- 辅助人只报自己切片；主负责人可对团队卡点一键「已知悉」。  
- 管理员在项目设置中指定。

## 正例

- 任务概述：热成像到货跟进  
- 做成了：热成像三套等设备；点位已勘完  
- 卡住：到货时间不定 · 跟进 9/12 · 影响 9 月底  
- 下一步：到货后安装，完成日随到货更新  

## 反例

- 下周只写「跟进项目进度」  
- 有明显故障却勾「无卡点」并写「正常」
